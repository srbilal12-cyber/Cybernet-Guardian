Signal guide: around −30 dBm is very strong; −50 to −60 dBm is usually good; −70 dBm is weaker; below −80 dBm is very weak. Signal strength does not reveal exact distance: walls, router power, frequency and interference all affect it. Never share your Wi-Fi password here.
06 / WI-FI SENSING LAB

Human Presence Demo (CSI)

Explore how Channel State Information (CSI) can change when movement disturbs Wi-Fi radio paths. This is a synthetic learning demo, not a live sensor and not a people counter.

Choose a scenario and run the simulation. The sample signal will appear here.
How real CSI works: compatible Wi-Fi hardware records channel measurements (often amplitude and phase across subcarriers). Software studies how those measurements change over time. Movement/presence detection may be possible after calibration; accurately counting people is much harder and is not guaranteed. This demo uses generated values only—no radio data is collected.
